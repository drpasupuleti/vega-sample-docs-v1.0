## Content Launcher Examples

<Tabs>
  <Tab title="Watch (play intent)">
    When a user says "Alexa, Watch Seabound", `autoPlay` is `true` and an `amzn_id` is present
    with no EPISODE entity — the intent resolves to `play`.

    ```typescript
    import { handleLaunchContent, EntityType } from 'vega-sample-package';

    const search = {
      entities: [
        {
          type: EntityType.VIDEO,
          externalIdList: [{ name: 'amzn_id', value: '1700000725' }],
        },
      ],
      searchKeyword: 'Seabound',
    };

    const payload = handleLaunchContent(search, true, { brandName: 'StreamCo' });

    console.log(payload.launchIntent); // "play"
    console.log(payload.amzn_id);      // "1700000725"
    ```
  </Tab>

  <Tab title="Find (search intent)">
    When a user says "Alexa, Find Seabound", `autoPlay` is `false` — the intent is always `search`.

    ```typescript
    import { handleLaunchContent, EntityType } from 'vega-sample-package';

    const search = {
      entities: [
        {
          type: EntityType.VIDEO,
          externalIdList: [{ name: 'amzn_id', value: '1700000725' }],
        },
      ],
      searchKeyword: 'Seabound',
    };

    const payload = handleLaunchContent(search, false, {});

    console.log(payload.launchIntent); // "search"
    ```
  </Tab>

  <Tab title="Episodic (playshow intent)">
    When a user says "Alexa, Play Season 1 Episode 5 from The SeaShow", `autoPlay` is `true`,
    an `amzn_id` is present, and EPISODE + SEASON entities exist — the intent resolves to `playshow`.

    ```typescript
    import { handleLaunchContent, EntityType } from 'vega-sample-package';

    const search = {
      entities: [
        {
          type: EntityType.VIDEO,
          externalIdList: [{ name: 'amzn_id', value: '1700000123' }],
        },
        { type: EntityType.EPISODE, value: '5', externalIdList: [] },
        { type: EntityType.SEASON, value: '1', externalIdList: [] },
      ],
      searchKeyword: 'The SeaShow season one episode five',
    };

    const payload = handleLaunchContent(search, true, {});

    console.log(payload.launchIntent);  // "playshow"
    console.log(payload.episodeNumber); // 5
    console.log(payload.seasonNumber);  // 1
    ```
  </Tab>

  <Tab title="Genre search">
    When a user says "Alexa, Find comedy movies", `autoPlay` is `false` and no `amzn_id` is
    present — the intent is `search`.

    ```typescript
    import { handleLaunchContent, EntityType } from 'vega-sample-package';

    const search = {
      entities: [
        { type: EntityType.GENRE, externalIdList: [] },
      ],
      searchKeyword: 'comedy movies',
    };

    const payload = handleLaunchContent(search, false, {});

    console.log(payload.launchIntent); // "search"
    ```
  </Tab>
</Tabs>

### Serialization Round-Trip

```typescript
import { handleLaunchContent, serializePayload, deserializePayload, EntityType } from 'vega-sample-package';

const search = {
  entities: [
    { type: EntityType.VIDEO, externalIdList: [{ name: 'amzn_id', value: '1700000123' }] },
    { type: EntityType.EPISODE, value: '5', externalIdList: [] },
    { type: EntityType.SEASON, value: '1', externalIdList: [] },
  ],
  searchKeyword: 'The SeaShow',
};

const payload = handleLaunchContent(search, true, {});
const json = serializePayload(payload);
const restored = deserializePayload(json);

console.log(restored.launchIntent);  // "playshow"
console.log(restored.episodeNumber); // 5
```

## Media Controls Examples

<Tabs>
  <Tab title="Basic handler">
    Implement `IMediaControlHandlerAsync` and wire it up with a `SessionManager`.

    ```typescript
    import {
      type IMediaControlHandlerAsync,
      PlaybackState,
      SessionManager,
    } from 'vega-sample-package';

    let positionMs = 0;
    let state = PlaybackState.IDLE;

    const handler: IMediaControlHandlerAsync = {
      async handlePlay()    { state = PlaybackState.PLAYING; },
      async handlePause()   { state = PlaybackState.PAUSED; },
      async handleStop()    { state = PlaybackState.STOPPED; positionMs = 0; },
      async handleSeek(ms)  { positionMs = ms; },
      async handleNext()    { /* load next track */ },
      async handlePrevious(){ /* load previous track */ },
      async handleFastForward() { /* increase speed */ },
      async handleRewind()      { /* decrease speed */ },
      async handleSkipForward(ms)  { positionMs += ms; },
      async handleSkipBackward(ms) { positionMs = Math.max(0, positionMs - ms); },
      async handleTogglePlayPause() {
        state = state === PlaybackState.PLAYING
          ? PlaybackState.PAUSED
          : PlaybackState.PLAYING;
      },
      async handleStartOver() { positionMs = 0; state = PlaybackState.PLAYING; },
    };

    const manager = new SessionManager();
    const session = manager.createSession({
      title: 'Planet Earth II — Mountains',
      playbackState: PlaybackState.IDLE,
      supportedControls: ['play', 'pause', 'stop', 'seek', 'skipForward', 'skipBackward'],
      capabilities: {
        canSeek: true, canSkipForward: true, canSkipBackward: true,
        canFastForward: false, canRewind: false, canSetPlaybackSpeed: true,
      },
      positionMs: 0,
      durationMs: 3600000,
    });

    // Listen for state changes
    manager.addListener(session.sessionId, (updated) => {
      console.log(`${updated.playbackState} at ${updated.positionMs}ms`);
    });

    // Handle a play command
    await handler.handlePlay();
    manager.updateSession(session.sessionId, {
      playbackState: state,
      positionMs,
    });
    ```
  </Tab>

  <Tab title="Picture-in-Picture">
    Create two independent sessions for a primary video and a PiP overlay.

    ```typescript
    import { PlaybackState, SessionManager, EndpointDiscovery } from 'vega-sample-package';

    const manager = new SessionManager();
    const discovery = new EndpointDiscovery();

    // Register two apps
    discovery.registerApp('com.example.streaming', 'Example Streaming');
    discovery.registerApp('com.example.sports', 'Example Sports');

    // Primary session (full-screen documentary)
    const primary = manager.createSession({
      title: 'Documentary — Deep Ocean',
      playbackState: PlaybackState.PLAYING,
      supportedControls: ['play', 'pause', 'stop', 'seek', 'skipForward', 'skipBackward'],
      capabilities: {
        canSeek: true, canSkipForward: true, canSkipBackward: true,
        canFastForward: false, canRewind: false, canSetPlaybackSpeed: true,
      },
      positionMs: 0,
      durationMs: 5400000,
    });

    // PiP session (live sports overlay)
    const pip = manager.createSession({
      title: 'Live — Championship Finals',
      playbackState: PlaybackState.PLAYING,
      supportedControls: ['play', 'pause', 'stop'],
      capabilities: {
        canSeek: false, canSkipForward: false, canSkipBackward: false,
        canFastForward: false, canRewind: false, canSetPlaybackSpeed: false,
      },
      positionMs: 0,
      durationMs: 7200000,
    });

    // Associate sessions with endpoints
    discovery.addSessionToEndpoint('com.example.streaming', primary.sessionId);
    discovery.addSessionToEndpoint('com.example.sports', pip.sessionId);

    // Sessions are independent — pausing PiP doesn't affect primary
    manager.updateSession(pip.sessionId, { playbackState: PlaybackState.PAUSED });

    const primaryState = manager.getSession(primary.sessionId);
    console.log(primaryState?.playbackState); // "playing" (unaffected)
    ```
  </Tab>
</Tabs>

<Warning>
  Always call `manager.destroySession(sessionId)` when playback ends to clean up resources
  and remove listeners. For endpoint discovery, also call `discovery.removeSessionFromEndpoint`
  and `discovery.unregisterApp` during cleanup.
</Warning>
