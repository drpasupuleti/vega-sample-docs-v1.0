# vega-sample-docs-v1.0

Mintlify documentation for the [vega-sample-package](https://github.com/drpasupuleti/vega-sample-package) — a TypeScript reference implementation demonstrating Vega OS Content Launcher and Media Controls APIs.

## Pages

- **introduction.mdx** — Overview, quick start, and package info
- **content-launcher.mdx** — Content Launcher API reference (types, functions, intent logic)
- **media-controls.mdx** — Media Controls API reference (SessionManager, EndpointDiscovery, handler interface)
- **examples.mdx** — End-to-end usage examples with tabbed code snippets

## Local Development

```bash
npx mintlify dev
```
