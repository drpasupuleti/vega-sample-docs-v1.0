# Media Controls API

The Media Controls API provides session-based media playback control supporting remote, voice, and touch inputs.

## Enums

### PlaybackState

Enum representing the current playback state.

```typescript
enum PlaybackState {
  IDLE = 'IDLE',
  PLAYING = 'PLAYING',
  PAUSED = 'PAUSED',
  BUFFERING = 'BUFFERING',
  STOPPED = 'STOPPED'
}
```

### RepeatMode

Enum representing the repeat mode for playback.

```typescript
enum RepeatMode {
  OFF = 'OFF',
  ONE = 'ONE',
  ALL = 'ALL'
}
```

## Types

### SupportedControl

Type representing the 12 supported control actions.

```typescript
type SupportedControl =
  | 'play'
  | 'pause'
  | 'stop'
  | 'seekForward'
  | 'seekBackward'
  | 'skipNext'
  | 'skipPrevious'
  | 'fastForward'
  | 'rewind'
  | 'setPosition'
  | 'setRepeatMode'
  | 'setShuffle';
```

### MediaSessionCapabilities

Type representing the 6 capability flags for a media session.

```typescript
interface MediaSessionCapabilities {
  canPlay: boolean;
  canPause: boolean;
  canSeek: boolean;
  canSkipNext: boolean;
  canSkipPrevious: boolean;
  canSetRepeatMode: boolean;
}
```

### MediaSession

Interface representing a media session.

```typescript
interface MediaSession {
  sessionId: string;
  title: string;
  playbackState: PlaybackState;
  supportedControls: SupportedControl[];
  capabilities: MediaSessionCapabilities;
  positionMs: number;
  durationMs: number;
}
```

### SessionListener

Callback type for session change notifications.

```typescript
type SessionListener = (session: MediaSession) => void;
```

### MediaEndpoint

Type representing a media endpoint for discovery.

```typescript
interface MediaEndpoint {
  endpointId: string;
  friendlyName: string;
  sessions: MediaSession[];
}
```

  // Speed controls

## Classes

### SessionManager

Manages media sessions with listener notification support.

```typescript
class SessionManager {
  // Create a new media session
  createSession(session: MediaSession): void;
  
  // Get a session by ID
  getSession(sessionId: string): MediaSession | null;
  
  // Update a session (notifies all listeners)
  updateSession(sessionId: string, updates: Partial<MediaSession>): void;
  
  // Destroy a session
  destroySession(sessionId: string): void;
  
  // Get all active sessions
  getAllSessions(): MediaSession[];
  
  // Add a session change listener
  addListener(listener: SessionListener): void;
  
  // Remove a session change listener
  removeListener(listener: SessionListener): void;
}
```

**Methods:**

| Method | Parameters | Returns | Description |
| --- | --- | --- | --- |
| `createSession` | `session: MediaSession` | `void` | Creates a new media session. |
| `getSession` | `sessionId: string` | `MediaSession \| null` | Retrieves a session by ID. |
| `updateSession` | `sessionId: string, updates: Partial<MediaSession>` | `void` | Updates a session and notifies listeners. |
| `destroySession` | `sessionId: string` | `void` | Destroys a session. |
| `getAllSessions` | none | `MediaSession[]` | Returns all active sessions. |
| `addListener` | `listener: SessionListener` | `void` | Adds a session change listener. |
| `removeListener` | `listener: SessionListener` | `void` | Removes a session change listener. |

### EndpointDiscovery

Manages endpoint registration and session association.

```typescript
class EndpointDiscovery {
  // Register an application endpoint
  registerApp(endpointId: string, friendlyName: string): void;
  
  // Unregister an application endpoint
  unregisterApp(endpointId: string): void;
  
  // List all registered endpoints
  listEndpoints(): MediaEndpoint[];
  
  // Get a specific endpoint
  getEndpoint(endpointId: string): MediaEndpoint | null;
  
  // Add a session to an endpoint
  addSessionToEndpoint(endpointId: string, session: MediaSession): void;
  
  // Remove a session from an endpoint
  removeSessionFromEndpoint(endpointId: string, sessionId: string): void;
}
```

**Methods:**

| Method | Parameters | Returns | Description |
| --- | --- | --- | --- |
| `registerApp` | `endpointId: string, friendlyName: string` | `void` | Registers an application endpoint. |
| `unregisterApp` | `endpointId: string` | `void` | Unregisters an application endpoint. |
| `listEndpoints` | none | `MediaEndpoint[]` | Lists all registered endpoints. |
| `getEndpoint` | `endpointId: string` | `MediaEndpoint \| null` | Gets a specific endpoint by ID. |
| `addSessionToEndpoint` | `endpointId: string, session: MediaSession` | `void` | Adds a session to an endpoint. |
| `removeSessionFromEndpoint` | `endpointId: string, sessionId: string` | `void` | Removes a session from an endpoint. |
