title: "Media Controls API"
description: "Integrate remote, voice, and touch input modalities for media playback control"
---

The Media Controls API provides functionality for integrating diverse input modalities — remote,
voice, and touch — for controlling media playback on Vega OS devices. It defines interfaces for
both client-side command dispatch and provider-side command handling, along with session metadata
and capability types.

## Architecture Overview

The Media Controls API has three main components:

<Columns cols={3}>
  <Card title="SessionManager" icon="layer-group">
    Manages the lifecycle of media sessions — creation, state updates, destruction, and listener notifications.
  </Card>
  <Card title="EndpointDiscovery" icon="radar">
    Registry for discovering integrated media provider apps and their active sessions.
  </Card>
  <Card title="Handler Interface" icon="gamepad">
    Provider-side interface that apps implement to respond to incoming control commands.
  </Card>
</Columns>

## Playback States

```typescript
enum PlaybackState {
  IDLE      = 'idle',       // No media loaded
  PLAYING   = 'playing',   // Actively playing
  PAUSED    = 'paused',    // Playback paused
  BUFFERING = 'buffering', // Loading/buffering
  STOPPED   = 'stopped',   // Playback stopped
}
```

## Supported Controls

A session advertises which controls it supports so the platform can enable or disable UI buttons:

```typescript
type SupportedControl =
  | 'play' | 'pause' | 'stop' | 'seek'
  | 'next' | 'previous'
  | 'fastForward' | 'rewind'
  | 'skipForward' | 'skipBackward'
  | 'togglePlayPause' | 'startOver';
```

## SessionManager

Manages the lifecycle of media sessions including creation, state updates, destruction, and
listener notifications. Supports multiple concurrent sessions for scenarios like picture-in-picture.

### createSession

Creates a new media session with a unique auto-generated identifier.

```typescript
const session = manager.createSession({
  title: 'Planet Earth II',
  playbackState: PlaybackState.PLAYING,
  supportedControls: ['play', 'pause', 'stop', 'seek'],
  capabilities: {
    canSeek: true, canSkipForward: true, canSkipBackward: true,
    canFastForward: false, canRewind: false, canSetPlaybackSpeed: true,
  },
  positionMs: 0,
  durationMs: 3540000,
});
```

### updateSession

Updates an existing session with partial state changes and notifies all registered listeners.

```typescript
const updated = manager.updateSession(session.sessionId, {
  playbackState: PlaybackState.PAUSED,
  positionMs: 45000,
});
```

### addListener / removeListener

Register or remove a callback to observe session state changes.

```typescript
const listener = (updated: MediaSession) => {
  console.log(`Now ${updated.playbackState} at ${updated.positionMs}ms`);
};

manager.addListener(session.sessionId, listener);
manager.removeListener(session.sessionId, listener);
```

### destroySession

Destroys a session and removes all associated listeners. Idempotent — safe to call multiple times.

```typescript
manager.destroySession(session.sessionId);
```

### getSession / getAllSessions

Retrieve a specific session by ID or list all active sessions.

```typescript
const session = manager.getSession('session-1');
const allSessions = manager.getAllSessions();
```

## EndpointDiscovery

Registry for discovering integrated media provider apps and their sessions.

```typescript
const discovery = new EndpointDiscovery();

// Register an app
discovery.registerApp('com.example.player', 'Example Player');

// Associate a session with the app
discovery.addSessionToEndpoint('com.example.player', session.sessionId);

// List all endpoints
const endpoints = discovery.listEndpoints();

// Look up a specific endpoint
const endpoint = discovery.getEndpoint('com.example.player');

// Clean up
discovery.removeSessionFromEndpoint('com.example.player', session.sessionId);
discovery.unregisterApp('com.example.player');
```

## Handler Interface

Media provider apps implement `IMediaControlHandlerAsync` to respond to incoming control commands
dispatched by the platform (remote, voice, touch).

```typescript
const handler: IMediaControlHandlerAsync = {
  async handlePlay()       { player.resume(); },
  async handlePause()      { player.pause(); },
  async handleStop()       { player.stop(); },
  async handleSeek(ms)     { player.seekTo(ms); },
  async handleNext()       { playlist.next(); },
  async handlePrevious()   { playlist.previous(); },
  async handleFastForward(){ player.fastForward(); },
  async handleRewind()     { player.rewind(); },
  async handleSkipForward(ms)  { player.skipForward(ms); },
  async handleSkipBackward(ms) { player.skipBackward(ms); },
  async handleTogglePlayPause(){ player.togglePlayPause(); },
  async handleStartOver()  { player.seekTo(0); },
};
```

<Tip>
  Each handler method is async and should return a Promise that resolves when the command
  has been processed. Update the session state via `SessionManager.updateSession` after
  handling each command so listeners are notified.
</Tip>
