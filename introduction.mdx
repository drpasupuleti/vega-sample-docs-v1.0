# Vega Sample Package

A TypeScript reference implementation demonstrating two core Vega OS APIs for Fire TV app development.

<Columns cols={2}>
  <Card title="Content Launcher API" icon="play" href="/content-launcher/overview">
    Integrate with the Fire TV home launcher and Alexa voice commands for content search and playback.
  </Card>
  <Card title="Media Controls API" icon="sliders-horizontal" href="/media-controls/overview">
    Handle diverse input modalities (remote, voice, touch) for media control on Vega OS devices.
  </Card>
</Columns>

## What's Inside

This package provides:

- **Type definitions** for both APIs with full TSDoc annotations
- **Processing logic** for content launch requests from Fire TV and Alexa
- **Session management** for media playback lifecycle
- **Endpoint discovery** for registering and querying media provider apps
- **Example modules** covering real-world integration scenarios

<Note>
  This package is intended as a reference implementation and documentation generation input.
  It is not a production runtime dependency.
</Note>
