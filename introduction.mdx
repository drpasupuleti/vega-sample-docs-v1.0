# Vega Sample Package

The vega-sample-package (v0.1.0) is a React Native + TypeScript reference SDK demonstrating two Vega OS APIs for Amazon Fire TV development.

## APIs

### Content Launcher API

The Content Launcher API integrates your application with the Fire TV launcher and Alexa voice commands. It enables:

- Content search through voice commands like "Alexa, find action movies"
- Direct playback via commands like "Alexa, watch The Grand Tour"
- Deep linking from the Fire TV home screen to specific content

### Media Controls API

The Media Controls API provides session-based media playback control supporting multiple input methods:

- Remote control navigation and playback buttons
- Alexa voice commands for play, pause, seek, and skip
- Touch input for supported devices
- Picture-in-Picture with multiple independent sessions

## Getting started

### Installation

```bash
npm install
```

Run type checking:

```bash
npm run typecheck
```

Run linting:

```bash
npm run lint
```

Build the package:

```bash
npm run build
```

Run tests:

