The **vega-sample-package** is a TypeScript reference implementation demonstrating two core Vega OS APIs
for Fire TV app developers. Use it as a starting point for integrating content discovery and media
playback controls into your app.

<Columns cols={2}>
  <Card title="Content Launcher API" icon="rocket" href="/content-launcher">
    Integrate with the Fire TV home launcher and Alexa voice commands for content search and playback.
  </Card>
  <Card title="Media Controls API" icon="circle-play" href="/media-controls">
    Support remote, voice, and touch input modalities for controlling media playback.
  </Card>
</Columns>

## Quick Start

<Steps>
  <Step title="Install the package">
    ```bash
    npm install vega-sample-package
    ```
  </Step>
  <Step title="Import the APIs">
    ```typescript
    import { handleLaunchContent, EntityType } from 'vega-sample-package';
    import { SessionManager, PlaybackState } from 'vega-sample-package';
    ```
  </Step>
  <Step title="Handle a content launch request">
    ```typescript
    const search = {
      entities: [
        { type: EntityType.VIDEO, externalIdList: [{ name: 'amzn_id', value: '1700000725' }] },
      ],
      searchKeyword: 'Seabound',
    };

    const payload = handleLaunchContent(search, true, {});
    console.log(payload.launchIntent); // "play"
    ```
  </Step>
  <Step title="Create a media session">
    ```typescript
    const manager = new SessionManager();

    const session = manager.createSession({
      title: 'My Video',
      playbackState: PlaybackState.PLAYING,
      supportedControls: ['play', 'pause', 'stop', 'seek'],
      capabilities: {
        canSeek: true, canSkipForward: true, canSkipBackward: true,
        canFastForward: false, canRewind: false, canSetPlaybackSpeed: false,
      },
      positionMs: 0,
      durationMs: 3600000,
    });
    ```
  </Step>
</Steps>
