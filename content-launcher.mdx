---
title: "Content Launcher API"
description: "Integrate with Fire TV home launcher and Alexa voice commands for content search and playback"
---

The Content Launcher API enables your Vega app to respond to content launch requests from the
Fire TV home launcher and Alexa voice commands. When a user says "Alexa, watch Seabound" or
"Alexa, find comedy movies", the platform dispatches a structured request that your app processes
using `handleLaunchContent`.

## How It Works

<Steps>
  <Step title="User issues a voice command or selects content">
    The Fire TV launcher or Alexa captures the user's intent and builds a content search request
    containing entities (VIDEO, EPISODE, SEASON, GENRE, ACTOR) and an optional search keyword.
  </Step>
  <Step title="Platform dispatches the request to your app">
    Your app receives an `IContentSearch` object with `autoPlay` set to `true` (direct playback)
    or `false` (show search results).
  </Step>
  <Step title="Your app processes the request">
    Call `handleLaunchContent(contentSearch, autoPlay, optionalFields)` to parse entities,
    extract identifiers, and determine the launch intent.
  </Step>
  <Step title="Act on the resolved intent">
    Use the returned `ContentLaunchPayload` to navigate to playback, search results, or
    episodic content.
  </Step>
</Steps>

## Launch Intent Logic

The intent is determined by the combination of `autoPlay`, the presence of an `amzn_id`, and
whether an `EPISODE` entity exists:

| `autoPlay` | `amzn_id` present | Has EPISODE entity | Result |
|:---:|:---:|:---:|:---:|
| `false` | any | any | `search` |
| `true` | yes | yes | `playshow` |
| `true` | yes | no | `play` |
| `true` | no | any | `search` |

## Entity Types

```typescript
enum EntityType {
  ACTOR   = 0,   // Actor or performer search
  GENRE   = 6,   // Genre-based search
  VIDEO   = 13,  // Movies, shows, or general video
  SEASON  = 14,  // Season of a TV show
  EPISODE = 15,  // Episode of a TV show
}
```

## Core Types

<AccordionGroup>
  <Accordion title="IContentSearch" icon="magnifying-glass">
    The top-level search request from the launcher or Alexa.

    <ParamField path="entities" type="IContentSearchEntity[]" required>
      List of content entities to search for.
    </ParamField>
    <ParamField path="searchKeyword" type="string">
      Free-text search keyword from the user's voice utterance.
    </ParamField>
  </Accordion>

  <Accordion title="IContentSearchEntity" icon="cube">
    A single entity within a content search request.

    <ParamField path="type" type="EntityType" required>
      The type of content entity (VIDEO, EPISODE, SEASON, GENRE, ACTOR).
    </ParamField>
    <ParamField path="value" type="string">
      The search value (e.g., episode number, season number).
    </ParamField>
    <ParamField path="externalIdList" type="IExternalId[]" required>
      External identifiers for cross-system content matching.
    </ParamField>
  </Accordion>

  <Accordion title="IExternalId" icon="fingerprint">
    An external identifier used to match content across systems.

    <ParamField path="name" type="string" required>
      The identifier namespace (e.g., `amzn_id`, `catalogContentId`).
    </ParamField>
    <ParamField path="value" type="string" required>
      The identifier value.
    </ParamField>
  </Accordion>

  <Accordion title="ContentLaunchPayload" icon="paper-plane">
    The processed output after parsing a content launch request.

    <ResponseField name="launchIntent" type="'play' | 'search' | 'playshow'" required>
      The determined launch intent.
    </ResponseField>
    <ResponseField name="searchKeyword" type="string">
      The search keyword from the original request.
    </ResponseField>
    <ResponseField name="amzn_id" type="string">
      The Amazon content identifier extracted from external IDs.
    </ResponseField>
    <ResponseField name="episodeNumber" type="number">
      Episode number for episodic content (only for `playshow` intent).
    </ResponseField>
    <ResponseField name="seasonNumber" type="number">
      Season number for episodic content (only for `playshow` intent).
    </ResponseField>
  </Accordion>
</AccordionGroup>

## Functions

### handleLaunchContent

Processes an incoming content launch request and returns a `ContentLaunchPayload`.

```typescript
function handleLaunchContent(
  contentSearch: IContentSearch,
  autoPlay: boolean,
  optionalFields: ILaunchContentOptionalFields,
): ContentLaunchPayload
```

<ParamField path="contentSearch" type="IContentSearch" required>
  The content search parameters from the launcher or Alexa.
</ParamField>
<ParamField path="autoPlay" type="boolean" required>
  Whether to auto-play content (`true`) or show search results (`false`).
</ParamField>
<ParamField path="optionalFields" type="ILaunchContentOptionalFields" required>
  Additional optional parameters (e.g., `brandName`, `metadata`).
</ParamField>

### serializePayload / deserializePayload

Round-trip a `ContentLaunchPayload` through JSON. Undefined fields are serialized as `null`.

```typescript
function serializePayload(payload: ContentLaunchPayload): string
function deserializePayload(json: string): ContentLaunchPayload
```

### extractAmznId

Extracts the first `amzn_id` value from a list of content search entities.

```typescript
function extractAmznId(entities: IContentSearchEntity[]): string | undefined
```

### determineIntent

Determines the launch intent based on `autoPlay`, `amzn_id`, and entity types.

```typescript
function determineIntent(
  autoPlay: boolean,
  amznId: string | undefined,
  entities: IContentSearchEntity[],
): LaunchIntent
```
