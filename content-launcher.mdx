# Content Launcher API

The Content Launcher API integrates your application with the Fire TV launcher and Alexa voice commands for content search and playback.

## Types

### EntityType

Enum representing the type of content entity.

```typescript
enum EntityType {
  ACTOR = 0,
  GENRE = 6,
  VIDEO = 13,
  SEASON = 14,
  EPISODE = 15
}
```

### LaunchIntent

Type representing the intent for launching content.

```typescript
type LaunchIntent = 'play' | 'search' | 'playshow';
```

### IExternalId

Interface for external identifier pairs.

```typescript
interface IExternalId {
  name: string;
  value: string;
}
```

### IContentSearchEntity

Interface for a content search entity.

```typescript
interface IContentSearchEntity {
  type: EntityType;
  value?: string;
  externalIdList: IExternalId[];
}
```

### IContentSearch

Interface for content search parameters.

```typescript
interface IContentSearch {
  entities: IContentSearchEntity[];
  searchKeyword?: string;
}
```

### ILaunchContentOptionalFields

Interface for optional launch content fields.

```typescript
interface ILaunchContentOptionalFields {
  brandName?: string;
  metadata?: Record<string, string>;
}
```

### ContentLaunchPayload

Interface for the content launch payload.

```typescript
interface ContentLaunchPayload {
  launchIntent: LaunchIntent;
  searchKeyword?: string;
  amzn_id?: string;
  episodeNumber?: number;
  seasonNumber?: number;
}
```

## Functions

### handleLaunchContent

Processes a content search request and returns a launch payload.

```typescript
function handleLaunchContent(
  contentSearch: IContentSearch,
  autoPlay: boolean,
  optionalFields?: ILaunchContentOptionalFields
): ContentLaunchPayload;
```

**Parameters:**

| Parameter | Type | Description |
| --- | --- | --- |
| `contentSearch` | `IContentSearch` | The content search parameters. |
| `autoPlay` | `boolean` | Whether to automatically play the content. |
| `optionalFields` | `ILaunchContentOptionalFields` | Optional fields including brand name and metadata. |

**Returns:** `ContentLaunchPayload` - The processed launch payload.

### extractAmznId

Extracts the Amazon ID from content search entities.

```typescript
function extractAmznId(
  entities: IContentSearchEntity[]
): string | undefined;
```

**Parameters:**

| Parameter | Type | Description |
| --- | --- | --- |
| `entities` | `IContentSearchEntity[]` | Array of content search entities. |

**Returns:** `string | undefined` - The Amazon ID if found, otherwise undefined.

### determineIntent

Determines the launch intent based on autoPlay flag and content entities.

```typescript
function determineIntent(
  autoPlay: boolean,
  amznId: string | undefined,
  entities: IContentSearchEntity[]
): LaunchIntent;
```

**Parameters:**

| Parameter | Type | Description |
| --- | --- | --- |
| `autoPlay` | `boolean` | Whether autoPlay is enabled. |
| `amznId` | `string \| undefined` | The Amazon ID if available. |
| `entities` | `IContentSearchEntity[]` | Array of content search entities. |

**Returns:** `LaunchIntent` - The determined launch intent.

### serializePayload

Serializes a content launch payload to JSON string.

```typescript
function serializePayload(
  payload: ContentLaunchPayload
): string;
```

**Parameters:**

| Parameter | Type | Description |
| --- | --- | --- |
| `payload` | `ContentLaunchPayload` | The payload to serialize. |

**Returns:** `string` - JSON string representation of the payload.

### deserializePayload

Deserializes a JSON string to a content launch payload.

```typescript
function deserializePayload(
  json: string
): ContentLaunchPayload;
```

**Parameters:**

| Parameter | Type | Description |
| --- | --- | --- |
| `json` | `string` | The JSON string to deserialize. |

**Returns:** `ContentLaunchPayload` - The deserialized payload.

## Intent determination

The launch intent is determined based on the `autoPlay` flag, presence of an Amazon ID, and entity types:

| autoPlay | amzn_id | Entity type | Intent |
| --- | --- | --- | --- |
| `false` | any | any | `search` |
| `true` | present | `EPISODE` | `playshow` |
| `true` | present | other | `play` |
| `true` | absent | any | `search` |
